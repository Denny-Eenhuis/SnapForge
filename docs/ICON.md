# SnapForge app icon

Original raster artwork generated with the built-in image generation tool. The source PNG retains transparency; the iconset contains 16, 32, 128, 256 and 512 point sizes at 1× and 2×. macOS iconutil packages them into AppIcon.icns.

Info.plist, the command-line release script and Xcode resource phase reference this icon. The monochrome menu bar symbol remains the native capture camera.

## Generation prompt

Use case: logo-brand
Asset type: macOS application icon for SnapForge, a local screenshot capture and annotation utility.
Primary request: one original, polished app icon, square canvas, a softly rounded native macOS tile with an unmistakable bold screenshot selection/capture frame enclosing a simple camera aperture and a small spark suggesting creation. Clean geometric silhouette, excellent legibility at Dock sizes, restrained dimensional finish and high contrast. One centered icon only, fills about 85% of canvas with consistent safe margins. No letters, words, watermarks, other logos, mockup desktop or presentation sheet. Transparent outside the rounded tile. Output a square high-resolution image suitable for a 1024px macOS icon.

Files: SnapForge/Resources/AppIcon-source.png, AppIcon.iconset, and AppIcon.icns.
